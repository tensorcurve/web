# TensorCurve 설치·운영 안내

이 ZIP은 워드프레스 관리자에서 직접 설치하는 클래식 테마입니다. 블록 편집기(Gutenberg)로 글과 페이지를 작성할 수 있습니다. 유료 빌더나 별도 필수 플러그인은 필요하지 않습니다. 기존에 확정한 밝은 영문 매체 디자인, TensorCurve 회사명, 가격 비교 도구를 포함합니다.

## 1. 설치

1. 나중에 호스팅과 워드프레스를 준비합니다. 테마를 보관하는 동안 호스팅을 결제할 필요는 없습니다.
2. 워드프레스 관리자 → 외모(Appearance) → 테마(Themes) → 새 테마 추가(Add New) → 테마 업로드(Upload Theme).
3. `TensorCurve-1.2.1.zip`을 압축 해제하지 않고 선택 → 지금 설치 → 활성화.
4. 외모 → TensorCurve Setup으로 이동합니다.
5. 새 사이트라면 Home/Guides 설정과 TensorCurve 이름 설정을 체크한 채 Create missing pages를 누릅니다.
6. 기존 사이트에서 설치할 경우 두 체크박스를 해제하면 기존 홈페이지 및 사이트 이름을 유지합니다. 기존 글과 페이지를 삭제하지 않습니다.

권장 설치 환경: 최신 안정 워드프레스와 PHP 8.3 이상. 테마 선언 최소 조건은 WordPress 6.5 / PHP 8.0입니다. 정확한 검증 버전과 범위는 VALIDATION.md를 확인하세요. 실호스팅 서버별 성능은 설치 후 확인해야 합니다.

## 2. 기본 페이지와 예시 글

초기 설정은 Home, Guides, Pricing Lab, Data Methodology를 공개 페이지로 생성합니다. About, Editorial Policy, Contact, Privacy는 실제 내용을 채워야 하므로 초안으로 생성합니다. 이 설정은 사이트의 검색 차단 여부를 바꾸지 않습니다.

예시 글이 필요하면 Import four synthetic educational sample articles as drafts를 선택합니다. 기존 시안의 영어 설명 글 4편이 **초안**으로 생성되며 자동 발행되지 않습니다. 글 목록에서 검토 후 개별 발행하면 메인과 카테고리에 나타납니다. 예시 글에는 합성 데이터 안내가 표시됩니다. 실제 콘텐츠를 넣을 때는 새 글을 작성하는 방식이 권장됩니다.

설정 버튼을 반복해서 눌러도 이미 만든 페이지와 예시 글을 중복 생성하지 않습니다. 테마 활성화만으로 글·페이지를 생성하지 않습니다. 다른 테마로 변경해도 입력한 글·페이지는 남습니다. 단, Pricing Lab 화면과 테마의 광고 shortcode는 TensorCurve 테마 기능입니다.

## 3. 글 입력과 디자인

- 글 → 새 글 추가: 제목, 본문, 카테고리를 입력합니다.
- 요약(Excerpt)은 메인과 기사 상단에 사용합니다. 비워 두면 목록에서 자동 요약합니다.
- 특성 이미지(Featured image)를 넣으면 기사 카드와 기사 상단에 표시합니다. 원본 이미지의 대체 텍스트와 캡션도 작성합니다.
- 본문 제목은 제목 2(H2)를 사용합니다. H2가 2개 이상이면 기사 목차가 자동으로 생성됩니다. 본문에 별도 H1을 넣지 않습니다.
- 카테고리는 실제 발행된 글이 있는 항목부터 탐색 메뉴에 표시합니다.
- 관련 글은 같은 카테고리를 우선하며, 없으면 다른 최신 글을 표시합니다.
- 작성자 이름과 소개는 사용자 → 프로필에서 관리합니다. 사용자 계정명이 그대로 노출되지 않도록 공개 표시 이름을 확인합니다.
- 기본 사이트 언어는 설정 → 일반에서 English로 선택하세요. 관리자 언어는 사용자 프로필에서 별도로 한국어로 지정할 수 있습니다.

외모 → 사용자 정의하기(Customize) → TensorCurve — Publication:

- Featured homepage article: 대표 글 선택. 기본값은 최신 발행 글입니다.
- Footer description: 하단 문구 변경.
- Public editorial email: 문의 페이지에서 공개할 실제 이메일. 입력하지 않으면 이메일 주소를 만들어서 표시하지 않습니다.
- Show editorial preview banner: 공개 전 예시 확인용 배너.

로고/사이트 아이콘은 사이트 아이덴티티에서 변경할 수 있습니다. 로고가 없으면 사이트 제목을 텍스트로 표시합니다. 기본 파비콘은 녹색 T입니다.

외모 → 메뉴에서 Main navigation과 Publication links 위치에 메뉴를 연결하면 직접 메뉴를 관리할 수 있습니다. 메뉴를 따로 지정하지 않으면 실제 존재하는 공개 페이지를 사용합니다. 초안 상태의 소개·개인정보 페이지는 방문자 메뉴에 표시하지 않습니다.

## 4. Pricing Lab

GPU(H100/H200/A100), 지역, 미래 시작일, 임대 기간을 변경할 수 있습니다. 기간별 곡선, 가격 행렬, 가상의 공급자 견적표가 연결됩니다. 이 기능은 브라우저에서 실행되며 Python 서버나 GPU가 필요하지 않습니다.

모든 값과 공급자명은 합성 예시입니다. 실제 GPU 시세 수집·API 연동은 포함되지 않습니다. 가격 모델과 720시간 월 환산 가정은 Data Methodology에 있습니다. 화면의 2026년 날짜는 예시 시나리오 날짜로, 실제 가격 확인일이 아닙니다.

## 5. 광고 영역

기본 상태에서는 광고 코드도, 빈 광고 박스도 표시하지 않습니다.

외모 → 사용자 정의하기 → TensorCurve — Advertising:

1. 배치만 보고 싶으면 Show non-clickable ad layout placeholders를 켭니다.
2. 실제 광고를 시작할 때 본인의 AdSense Publisher ID (`ca-pub-` + 숫자 16자리)를 입력합니다.
3. 직접 만든 반응형 디스플레이 광고 단위의 슬롯 ID를 Homepage / Article에 각각 입력합니다.
4. 개인정보 안내와 필요한 동의 관리 설정을 완료한 다음 Enable real AdSense display units를 켭니다.

홈에는 기사 목록 뒤 1개, 기사에는 기본적으로 본문 뒤 1개가 표시됩니다. **기사 중간**에 넣으려면 두 개 이상의 설명 단락 다음 등 자연스러운 구간에 Shortcode 블록을 추가하고 `[tensorcurve_ad]`를 입력합니다. 같은 기사에 중복으로 넣어도 광고 1개만 출력하고, 본문 뒤의 중복 영역은 생략합니다.

광고 코드를 동일한 위치에 다른 플러그인으로 중복 삽입하지 마세요. 테마의 수동 광고 슬롯과 AdSense 자동 광고는 별도 설정입니다. 자동 광고를 켜면 테마에서 정한 것 외에 광고가 나타날 수 있습니다. ads.txt는 본인 애드센스 계정이 제공하는 실제 값으로 별도 설정해야 하며 이 테마는 임의의 파일이나 계정 번호를 만들지 않습니다.

이 테마는 동의 관리 플랫폼(CMP)을 포함하지 않습니다. 대상 국가 및 서비스에 필요한 CMP/쿠키 동의 설정은 실제 광고·분석 도입 시 완료해야 합니다. 광고 계정 승인이나 수익을 보장하지 않습니다.

## 6. 검색 노출

제목, 발행일, 작성자, 기사 URL 등은 워드프레스의 실제 정보를 사용합니다. WordPress가 단일 글의 canonical과 기본 사이트맵을 제공합니다. 테마는 기본 설명과 Article 구조화 데이터를 추가하며 Yoast, Rank Math, AIOSEO, SEOPress, The SEO Framework가 감지되면 테마의 추가 SEO 출력을 끕니다.

SEO 플러그인은 하나만 사용하세요. 현재 시안의 chatgpt.site 주소나 고정 noindex는 테마에 들어 있지 않습니다. 개발 중에는 설정 → 읽기 → 검색 엔진 접근 차단을 사용하고, 공개 시 해제 여부를 확인하세요. 비밀번호/호스팅 접근 제한은 별개입니다. Search Console 소유권 확인과 사이트맵 제출은 도메인 연결 후 진행합니다.

## 7. 공개 전 확인

- 임시/초안 문구 대신 실제 운영자·연락처·개인정보 안내 입력
- 예시 가격을 실제 시세처럼 표시하지 않는지 확인
- 모바일 기사·이미지·표와 메뉴 작동 확인
- HTTPS, 백업·복원 방법, 최신 업데이트 확인
- 실제 호스팅에서 관리자 응답 속도와 메모리 확인
- 광고는 실제 승인·계정·동의 설정 후 활성화

## 1.1 콘텐츠 업데이트

승인된 디자인에 Verda 공개 요금과 기간별 할인율로 계산한 커브를 반영했습니다. 2026-09-13 확인 스냅샷이며 자동 갱신은 아직 활성화하지 않았습니다. H100/H200/A100 각각 1·3·6·12개월 값을 포함합니다. 미래 시작일·지역별 가격은 추정하지 않습니다.

새 설치: Appearance → TensorCurve Setup에서 영문 기사 4편을 초안으로 가져와 검토 후 발행하세요. 기존 설치: 기존 글과 Methodology 페이지는 덮어쓰지 않습니다. 이미 가져온 글이 있다면 inc/sample-content.json과 inc/methodology.html의 새 원고를 해당 글·페이지에 반영하세요. 출처·확인일을 보존하세요.


## 1.2 자동 갱신

1.2.0부터 Pricing Lab 데이터는 매일 자동으로 갱신됩니다.

- GitHub 저장소의 Actions 작업이 매일 05:17 UTC(한국 시간 14:17)에 Verda 공개 요금 페이지를 읽어 `tensorcurve/assets/data/pricing-snapshot.json`(및 CSV, JS, 누적 이력 CSV)을 갱신하고 `main` 브랜치에 커밋합니다.
- 테마는 그 JSON을 GitHub에서 읽어 6시간 동안 캐시합니다. 읽기에 실패하면 마지막 성공본, 그다음 테마에 내장된 파일 순으로 대체하므로 화면이 비는 일은 없습니다.
- 추출값이 검증(3개 구성 모두 존재, 가격 범위, 할인율 증가, 급격한 변동 없음)을 통과하지 못하면 아무것도 갱신하지 않고 이전 스냅샷과 확인일을 유지합니다.
- 외모 → 사용자 정의하기 → TensorCurve — Pricing data에서 자동 갱신을 끄거나 다른 피드 URL을 지정할 수 있습니다.
- 홈 화면의 H100 곡선과 미니 표, Pricing Lab의 확인일, JSON/CSV 다운로드(`/?tc_pricing=json`, `/?tc_pricing=csv`)가 모두 같은 데이터에서 생성됩니다.

기존 1.1.0 설치에서 업그레이드할 때: 테마 ZIP을 업로드해 교체하면 됩니다. 단, Data Methodology 페이지 본문은 데이터베이스에 저장된 글이므로 자동으로 바뀌지 않습니다. `inc/methodology.html`의 새 본문(수집·갱신 방식과 다운로드 링크)을 해당 페이지에 다시 붙여 넣으세요.
